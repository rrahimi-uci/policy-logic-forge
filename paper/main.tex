\begin{abstract}
Normative documents are often converted into decision logic by systems whose outputs are difficult to audit, execute, or compare. We present LEXEC, a bounded compiler and review protocol that makes a declared subset of normative text executable while retaining source evidence, refusal states, and validation traces. The contribution is an instrument: typed intermediate representation, total fail-closed lowering, bounded FEEL/reference evaluation, DMN emission, solver-backed checks, and a run contract expose which properties are decidable inside the supported subset and which remain semantic or legal judgments. We describe the complete implementation and an evidence-gated evaluation plan spanning source fidelity, executable behavior, and review reliability. The current checkout passes its engineering contract and contains exploratory and fixture-only artifacts, but it does not yet contain the licensed annotations, independent engine comparison, or preregistered human observations required for a scientific quality claim. We therefore report implementation facts and non-results explicitly and give a reproducible path from the present snapshot to a defensible NeurIPS evaluation.
\end{abstract}
