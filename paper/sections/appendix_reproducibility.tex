\section{Reproducibility checklist}

The release bundle records the source commit, Python lock and platform
metadata, model/provider configuration when applicable, random seeds, input and
output hashes, schema versions, validator logs, and exclusion/stop-rule
records. A local reviewer can run the deterministic suite and compile this
paper without licensed corpora. Licensed or provider-dependent experiments are
represented by manifests and explicit `blocked' or `unrun' statuses until
their inputs and observations are available.
