The current checkout is implementation-complete for the planned engineering
surface and evidence-incomplete for the scientific surface. Table
\ref{tab:implementation} records facts that can be checked locally. The
counts describe tests and retained artifacts, not accuracy.

The end-to-end privacy-policy run processed \PrivacyFiles{} source files in
\PrivacyChunks{} chunks, completed \PrivacyBatches{} of \PrivacyBatches{} batches,
dropped no bytes, and retained \PrivacyRules{} final rules. Before grounding,
\PrivacyReady{} rules were ready and \PrivacyReview{} required review. Grounding
certified \PrivacyCertified{} rules and failed \PrivacyFailed{}, with complete
response coverage. This is an
operational, exploratory observation: provider behavior, corpus licensing, and
the absence of independent labels preclude an AFS or OE claim. The high failure
rate is useful for hardening the review path and is not evidence that the
source or compiler is incorrect.

The retained dependency output contains \PrivacyDags{} generated DAGs, including
\PrivacyMultiRuleDags{} multi-rule DAGs and one condensed cycle group. This
reports graph coverage and review workload; it is not dependency precision or
recall.

The repository's deterministic suite currently collects 1,051 core Python
tests. Plan, configuration, research-artifact, and G0 evidence validators also
pass. These checks establish contract integrity and regression protection; they
do not establish that extracted rules are legally or semantically correct.
