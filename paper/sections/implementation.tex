\section{Artifact implementation}

The repository implements the complete local path needed to exercise the
instrument: versioned extraction and IR contracts, fail-closed lowering,
bounded FEEL and solver evaluation, DMN serialization, run-bundle validation,
statistics, perturbation contracts, and a provenance-first review UI. The paper
build reads retained JSON artifacts, verifies an available restricted bundle
against SHA-256 hashes, and generates all reported counts and plot labels.
Source checks reject missing bibliography entries, modified template files,
unresolved inputs, and forbidden claims.

The artifact distinguishes \emph{implemented} from \emph{measured}. Local tests
establish contract integrity and regression protection, not extraction
accuracy. Provider-dependent runs, licensed annotations, and external-engine
observations remain unavailable until their own manifests satisfy the protocol.
This separation is enforced by aggregate validators and by the claim ledger
included with the paper.
