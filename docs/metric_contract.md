# Metric contract

`AFS` is an artifact-free source-grounded signal. `sOE` is source-originated
execution whose labels come from the gold artifact. `OE` is oracle execution
against gold. `EY` is executable yield, and `CQI` is conditional quality among
compiled units—not correctness by itself. Every report must retain the
`model × system × run` observation row and state which of these measures are
gold-labelled.
