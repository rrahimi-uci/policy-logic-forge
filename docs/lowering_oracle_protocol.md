# LOWER-1 lowering oracle protocol

`tests/fixtures/lowering_oracle/cases.json` is the frozen, provider-free
oracle fixture for the v2-to-LExec boundary.  Expected projections are
authored directly in the fixture; they do not call private lowering helpers.
The harness invokes only the public `lower_graph` API and removes provenance
from the comparison projection so source-location formatting cannot hide a
semantic mismatch.

The fixture covers:

- boolean equality and assignment modality;
- justified string `contains`;
- unsupported date theory refusal;
- unrepresentable structured scope refusal; and
- exception formula composition.

The six mutations flip a predicate operator, flip modality, remove condition
logic, inject an unsupported scope field, remove source provenance, and replace
a supported variable type with `date`.  A mutation is **killed** only when its
observable projection differs from the unmutated projection.  A surviving
mutation is a correctness failure even if another backend agrees with the
same lowered output.

`results/aggregates/lowering_mutation_score.json` is generated by
`scripts/lowering_mutation.py` and checked in with `--check`.  The current
result is five of five cases and six of six mutations, with
`status: fixture_only`.  It is a regression gate, not a corpus-level lowering
accuracy estimate; corpus claims still require independently annotated,
licensed data and adjudication.
